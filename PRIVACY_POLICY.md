## 1. Overview
This Privacy Policy outlines how our automated publishing tools, desktop applications, and APIs collect, use, and protect information when you interact with our datasets, marketing tools, and connected services (including YouTube and TikTok integrations).

## 2. Information We Collect
- **Developer & User Account Data:** When authorized, our publishing tools interact with YouTube Data API v3 and TikTok Content Posting API v2 using OAuth 2.0. We access only the minimum necessary scopes required to publish user-created marketing videos and post relevant metadata (titles, descriptions, tags, and pinned comments).
- **No Personal Data Selling:** We do not sell, rent, or trade your personal information, API tokens, or login credentials to third parties under any circumstances.
- **Local Token Storage:** All authentication tokens (`youtube_token.json`, `tiktok_token.json`) are stored locally on your machine and are never transmitted to external servers.

## 3. Use of Information
We use the granted permissions solely to:
1. Upload and schedule user-generated promotional short-form videos.
2. Publish video metadata, captions, and links to public datasets and storefronts.
3. Retrieve engagement analytics (view counts, comments, and ratings) to provide actionable customer intelligence digests.

## 4. Third-Party Services
Our services integrate with third-party APIs:
- **Google & YouTube API Services:** Use of YouTube API data adheres to the [Google Privacy Policy](https://policies.google.com/privacy) and [YouTube Terms of Service](https://www.youtube.com/t/terms).
- **TikTok Developer API:** Use of TikTok API data adheres to the [TikTok Privacy Policy](https://www.tiktok.com/legal/page/row/privacy-policy/en).

## 5. Revocation of Access
You can revoke our application's access at any time:
- For Google/YouTube: Visit [Google Security Account Settings](https://myaccount.google.com/permissions).
- For TikTok: Visit TikTok App Settings -> Security & Logins -> Manage App Permissions.
